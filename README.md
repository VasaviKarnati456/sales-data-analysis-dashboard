# Sales Data Analysis Dashboard

## Project Overview

The Sales Data Analysis Dashboard is a data analytics project developed using Python, Streamlit, Pandas, and Plotly. It helps analyze sales performance, profit, product categories, regions, and payment methods through interactive charts and visualizations.

## Objectives

* Analyze total sales and profit.
* Identify top-performing products and categories.
* Compare sales across different regions.
* Understand customer payment method preferences.
* Present business insights through an interactive dashboard.

## Tools and Technologies

* **Python** – Data analysis and application development
* **Pandas** – Data cleaning and manipulation
* **Streamlit** – Interactive dashboard development
* **Plotly** – Data visualization
* **Excel/CSV** – Sales data storage

## Dataset

The dataset contains sales information such as:

* Order ID
* Order Date
* Region
* State
* Category
* Product
* Sales
* Profit
* Quantity
* Payment Mode

## Dashboard Features

* Sales and profit analysis
* Category-wise sales comparison
* Region-wise performance analysis
* Product performance analysis
* Payment mode analysis
* Interactive charts and visualizations

## How to Run the Project

1. Install Python on your computer.

2. Download or clone this repository.

3. Open the project folder in Command Prompt or a terminal.

4. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the dashboard:

   ```bash
   streamlit run app.py
   ```

6. Open the local URL displayed in the terminal.
